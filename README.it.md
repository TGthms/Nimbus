# Nimbus

App meteo nativa per macOS: scene cinematografiche, previsioni [Open-Meteo](https://open-meteo.com/), ispettore Pro, extra nella barra dei menu e widget.

**Lingue:** [English](README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Nederlands](README.nl.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

Apri `Nimbus.xcodeproj` o l’app da una Release. macOS 15+.

La barra laterale include **La mia posizione** e città popolari. Cerca altre città e tocca **Aggiungi**. Lingua e unità seguono il sistema finché non le cambi in Impostazioni. **Fine** chiude il foglio. Un clic su una scheda apre un overlay.

Dati Open-Meteo, nessuna chiave API.
