# Nimbus

原生 macOS 天氣應用：電影感天空、[Open-Meteo](https://open-meteo.com/) 詳細預報、專業檢查器、選單列與小工具。

**語言：** [English](../../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Nederlands](README.nl.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

開啟 `Nimbus.xcodeproj` 或 Release 中的 `.app`。需要 macOS 15+。

側邊欄包含**我的位置**與熱門城市。搜尋其他城市並點**加入**。語言與單位預設跟隨系統，可在設定覆寫。點**完成**關閉設定。點卡片會跳出疊加詳情，而不是把格子撐開。

資料來自 Open-Meteo，無需 API 金鑰。**我的位置**只使用約一公里的概略座標，不使用精確 GPS。
