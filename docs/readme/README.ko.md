# Nimbus

macOS 네이티브 날씨 앱. 영화 같은 하늘, [Open-Meteo](https://open-meteo.com/) 상세 예보, Pro 검사기, 메뉴 막대, 위젯.

**언어:** [English](../../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Nederlands](README.nl.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

`Nimbus.xcodeproj` 또는 Release의 `.app`을 엽니다. macOS 15+.

사이드바에 **내 위치**와 주요 도시가 있습니다. 다른 도시는 검색 후 **추가**. 언어와 단위는 설정에서 바꾸기 전까지 시스템을 따릅니다. 설정은 **완료**로 닫습니다. 카드를 누르면 오버레이 상세가 열립니다.

데이터는 Open-Meteo. API 키 없음. **내 위치**는 대략적인 위치만 사용합니다(약 1km, 정밀 GPS 아님).
