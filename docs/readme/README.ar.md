# Nimbus

تطبيق طقس أصلي لـ macOS: مشاهد سينمائية، توقعات مفصّلة من [Open-Meteo](https://open-meteo.com/)، مفتش احترافي، عنصر في شريط القوائم، وودجات.

**اللغات:** [English](../../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Nederlands](README.nl.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

افتح `Nimbus.xcodeproj` أو التطبيق من الإصدارات. macOS 15+.

يبدأ الشريط الجانبي بـ **موقعي** ومدن شائعة. ابحث عن أي مدينة واضغط **إضافة**. اللغة والوحدات تتبعان النظام حتى تغيّرهما في الإعدادات. **تم** يغلق الورقة. النقر على بطاقة يفتح تفاصيل عائمة.

البيانات من Open-Meteo دون مفتاح واجهة. **موقعي** يستخدم موقعًا تقريبيًا فقط (~1 كم) وليس تحديدًا دقيقًا.
