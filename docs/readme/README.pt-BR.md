# Nimbus

App nativo de clima para macOS: cenas cinematográficas, previsões detalhadas do [Open-Meteo](https://open-meteo.com/), inspetor Pro, extra na barra de menus e widgets.

**Idiomas:** [English](../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Nederlands](README.nl.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

Abra `Nimbus.xcodeproj` ou o `.app` de uma Release. macOS 15+.

A barra lateral começa com **Minha localização** e cidades populares. Pesquise qualquer cidade e toque em **Adicionar**. Idioma e unidades seguem o sistema até você alterar em Ajustes. **Concluído** fecha a folha. Um clique no cartão abre um detalhe sobreposto.

Dados do Open-Meteo, sem chave de API. **Minha localização** usa só posição aproximada (~1 km), não GPS preciso.
